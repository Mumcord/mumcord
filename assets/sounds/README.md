# Notification sounds

Short, soft tones for FR-1.27 (join/leave, self mute/deafen, new message, own voice join,
hang up). No speech.

All sounds are generated by ElevenLabs; see [ElevenLabs sounds](#elevenlabs-sounds).

Format: 48 kHz, mono, 16-bit PCM. Peak about -18 dBFS. Embedded into the engine with
`include_bytes!` (`crates/engine/src/sounds.rs`).

| File                            | Event                                                        |
| ------------------------------- | ------------------------------------------------------------ |
| user_joined.wav / user_left.wav | someone joins / leaves your channel (rising / falling)       |
| mute.wav / unmute.wav           | you mute / unmute                                            |
| deafen.wav / undeafen.wav       | you deafen / undeafen                                        |
| message.wav                     | new message in a followed channel or private chat            |
| mention.wav                     | someone mentions you (`@Name`); replaces message.wav (QA.41) |
| voice_join.wav                  | you join a channel for voice (QA.23)                         |
| hang_up.wav                     | you disconnect from a server (QA.19)                         |
| kicked.wav                      | the server kicks you (#205)                                  |
| banned.wav                      | the server bans you (#205)                                   |

## ElevenLabs sounds

voice_join.wav is the sound for being connected and joining voice, and is also reused for the
party-started and share-started activity sounds. hang_up.wav is also reused for share stopped.

- Source: ElevenLabs sound effects ("Elegant device"), generated 2026-11-01.
- Licence: generated under a paid ElevenLabs plan; commercial use permitted, no attribution required.
  They are not CC0.
- Processing (all of them): converted to 48 kHz mono 16-bit PCM, 3 ms fade-in, normalized to a -18 dBFS
  peak.
  - voice_join.wav: "Elegant device", trimmed from 2 s to 1.2 s (near-silent tail), 150 ms fade-out.
  - message.wav: "Elegant new message", trimmed from 1.48 s to 1.0 s, 150 ms fade-out. Replaces the
    generic new-message sound for channel and private messages; mentions keep mention.wav.
  - mute.wav: "Microphone mute", trimmed to 0.35 s (the click starts after 0.1 s of silence, the tail
    is near silent), 40 ms fade-out. Plays on self-mute.
  - unmute.wav: "Microphone unmute", 0.12 s to 0.42 s (0.30 s), 40 ms fade-out. Plays on self-unmute.
  - deafen.wav: "Headphone audio" (deafen take), 0.12 s to 0.37 s (0.25 s), 40 ms fade-out.
  - undeafen.wav: "Headphone audio" (undeafen take), first 0.25 s, 40 ms fade-out.
  - kicked.wav: "User kicked from server", first 1.0 s of 1.48 s, 150 ms fade-out. Plays when the server
    kicks you.
  - banned.wav: "User banned from server", first 1.0 s of 1.48 s, 150 ms fade-out. Plays when the server
    bans you.
  - mention.wav: "Mention notification", first 0.7 s of 1.0 s, 150 ms fade-out. Plays when someone
    mentions you.
  - hang_up.wav: "Leaving a voice", first 0.9 s of 1.48 s, 150 ms fade-out. Plays when you leave voice
    or disconnect.
  - user_joined.wav: "Someone joining", first 0.8 s of 1.48 s, 150 ms fade-out. Plays when someone joins
    your channel; also used for party joined and viewer started.
  - user_left.wav: "Someone leaving", first 0.8 s of 1.48 s, 150 ms fade-out. Plays when someone leaves
    your channel; also used for party left and viewer stopped.
