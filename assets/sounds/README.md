# Notification sounds

Short, soft tones for FR-1.27 (join/leave, self mute/deafen, new message, own voice join,
hang up). No speech.

All sounds except voice_join.wav, message.wav, mute.wav, kicked.wav and banned.wav are synthesized from scratch by `generate.py`
(plain sine tones with a small second harmonic, fast attack, exponential decay; stdlib only). No
third-party audio is used for them, so there is nothing to attribute. They are dedicated to the
public domain under CC0 1.0. voice_join.wav, message.wav, mute.wav, kicked.wav and banned.wav are
generated by ElevenLabs; see [Connect, message and mute sounds](#connect-message-and-mute-sounds)
and [Kicked and banned](#kicked-and-banned-205).

Format: 48 kHz, mono, 16-bit PCM. Peak about -18 dBFS, all under 400 ms (except voice_join.wav,
message.wav and banned.wav, see below). Embedded into the
engine with `include_bytes!` (`crates/engine/src/sounds.rs`); regenerate with
`python3 generate.py`.

| File                            | Event                                                        |
| ------------------------------- | ------------------------------------------------------------ |
| user_joined.wav / user_left.wav | someone joins / leaves your channel (rising / falling)       |
| mute.wav / unmute.wav           | you mute / unmute                                            |
| deafen.wav / undeafen.wav       | you deafen / undeafen                                        |
| message.wav                     | new message in a followed channel or private chat            |
| mention.wav                     | someone mentions you (`@Name`); replaces message.wav (QA.41) |
| voice_join.wav                  | you join a channel for voice (QA.23)                         |
| hang_up.wav                     | you disconnect from a server (QA.19)                         |
| kicked.wav                      | the server kicks you (#205)                                  |
| banned.wav                      | the server bans you (#205)                                   |

## Connect, message and mute sounds

voice_join.wav is not synthesized by `generate.py`. It is the sound for being connected and joining
voice, and is also reused for the party-started and share-started activity sounds.

- Source: ElevenLabs sound effects ("Elegant device"), generated 2026-11-01.
- Licence: generated under a paid ElevenLabs plan; commercial use permitted, no attribution required.
  It is not CC0, unlike the synthesized sounds here.
- Processing (all three): converted to 48 kHz mono 16-bit PCM, 3 ms fade-in, normalized to a -18 dBFS
  peak.
  - voice_join.wav: "Elegant device", trimmed from 2 s to 1.2 s (near-silent tail), 150 ms fade-out.
  - message.wav: "Elegant new message", trimmed from 1.48 s to 1.0 s, 150 ms fade-out. Replaces the
    generic new-message sound for channel and private messages; mentions keep mention.wav.
  - mute.wav: "Microphone mute", trimmed to 0.35 s (the click starts after 0.1 s of silence, the tail
    is near silent), 40 ms fade-out. Plays on self-mute only; unmute.wav is unchanged.

## Kicked and banned (#205)

kicked.wav and banned.wav are not synthesized by `generate.py`:

- Source: ElevenLabs sound effects (`eleven_text_to_sound_v2`), generated 2026-10-30.
- Licence: generated under a paid ElevenLabs plan; commercial use permitted, no attribution required.
  They are not CC0, unlike the other sounds here.
- Processing: converted to 48 kHz mono 16-bit PCM and normalized to a -18 dBFS peak. The near-silent
  tail of kicked.wav was trimmed (with a 10 ms fade-out) to 227 ms. banned.wav keeps its full
  1 s because it has two parts (the impact, then a short comedic squeak).

| File       | Prompt                                                                                                                                                                          |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| kicked.wav | "Single sharp face slap, crisp comedic hand slap on cheek, punchy, dry, no voice, no music" (0.5 s, prompt influence 0.85, take 1 of 4)                                         |
| banned.wav | "Cartoon slapstick kick to the groin, dull thump impact followed by a short comedic high-pitched male squeak \"oof\", funny, no music" (1 s, prompt influence 0.8, take 3 of 4) |
