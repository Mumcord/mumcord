# Notification sounds

Short, soft sounds for FR-1.27 (join/leave, self mute/deafen, new message, own voice join,
hang up, quit). No speech.

There are two sound themes (#325), chosen in Settings > Sounds:

- [`classic/`](#classic): the short tones Mumcord started with, synthesized by `generate.py`.
- [`rich/`](#rich) (the default): fuller sounds generated by ElevenLabs.

Both folders hold the same file names. The engine embeds both sets with `include_bytes!`
(`crates/engine/src/sounds.rs`) and plays the file of the chosen theme; a file one theme lacks
plays from the other.

Format: 48 kHz, mono, 16-bit PCM. Peak about -18 dBFS.

| File                            | Event                                                        |
| ------------------------------- | ------------------------------------------------------------ |
| user_joined.wav / user_left.wav | someone joins / leaves your channel                          |
| mute.wav / unmute.wav           | you mute / unmute                                            |
| deafen.wav / undeafen.wav       | you deafen / undeafen                                        |
| message.wav                     | new message in a followed channel or private chat            |
| mention.wav                     | someone mentions you (`@Name`); replaces message.wav (QA.41) |
| voice_join.wav                  | you join a channel for voice (QA.23)                         |
| hang_up.wav                     | you disconnect from a server (QA.19)                         |
| quit.wav                        | you quit Mumcord while in a voice channel (#325)             |
| kicked.wav                      | the server kicks you (#205)                                  |
| banned.wav                      | the server bans you (#205)                                   |

In both themes, voice_join.wav is also used for the party-started and share-started activity
sounds, hang_up.wav for share stopped, user_joined.wav for party joined and viewer started, and
user_left.wav for party left and viewer stopped.

## Classic

All classic sounds except kicked.wav and banned.wav are synthesized from scratch by
`classic/generate.py` (plain sine tones with a small second harmonic, fast attack, exponential
decay; stdlib only). No third-party audio is used for them, so there is nothing to attribute.
They are dedicated to the public domain under CC0 1.0. All stay under 500 ms. Regenerate them
with `python3 classic/generate.py`; it writes the files next to itself.

### Kicked and banned (#205)

The classic kicked.wav and banned.wav are not synthesized by `generate.py`:

- Source: ElevenLabs sound effects (`eleven_text_to_sound_v2`), generated 2026-10-30.
- Licence: generated under a paid ElevenLabs plan; commercial use permitted, no attribution required.
  They are not CC0, unlike the other classic sounds.
- Processing: converted to 48 kHz mono 16-bit PCM and normalized to a -18 dBFS peak. The near-silent
  tail of kicked.wav was trimmed (with a 10 ms fade-out) to 227 ms. banned.wav keeps its full
  1 s because it has two parts (the impact, then a short comedic squeak).

| File       | Prompt                                                                                                                                                                          |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| kicked.wav | "Single sharp face slap, crisp comedic hand slap on cheek, punchy, dry, no voice, no music" (0.5 s, prompt influence 0.85, take 1 of 4)                                         |
| banned.wav | "Cartoon slapstick kick to the groin, dull thump impact followed by a short comedic high-pitched male squeak \"oof\", funny, no music" (1 s, prompt influence 0.8, take 3 of 4) |

## Rich

- Source: ElevenLabs sound effects (`eleven_text_to_sound_v2`), generated 2026-11-01 and picked by
  the product owner.
- Licence: generated under a paid ElevenLabs plan; commercial use permitted, no attribution required.
  They are not CC0.
- Processing (all of them): converted to 48 kHz mono 16-bit PCM, 3 ms fade-in, normalized to a
  -18 dBFS peak.
  - voice_join.wav: "Elegant device", trimmed from 2 s to 1.2 s (near-silent tail), 150 ms fade-out.
  - message.wav: "Elegant new message", trimmed from 1.48 s to 1.0 s, 150 ms fade-out.
  - mute.wav: "Microphone mute", trimmed to 0.35 s (the click starts after 0.1 s of silence, the tail
    is near silent), 40 ms fade-out.
  - unmute.wav: "Microphone unmute", 0.12 s to 0.42 s (0.30 s), 40 ms fade-out.
  - deafen.wav: "Headphone audio" (deafen take), 0.12 s to 0.37 s (0.25 s), 40 ms fade-out.
  - undeafen.wav: "Headphone audio" (undeafen take), first 0.25 s, 40 ms fade-out.
  - kicked.wav: "User kicked from server", first 1.0 s of 1.48 s, 150 ms fade-out.
  - banned.wav: "User banned from server", first 1.0 s of 1.48 s, 150 ms fade-out.
  - mention.wav: "Mention notification", first 0.7 s of 1.0 s, 150 ms fade-out.
  - hang_up.wav: "Leaving a voice", first 0.9 s of 1.48 s, 150 ms fade-out.
  - user_joined.wav: "Someone joining", first 0.8 s of 1.48 s, 150 ms fade-out.
  - user_left.wav: "Someone leaving", first 0.8 s of 1.48 s, 150 ms fade-out.
  - quit.wav: "Elegant device", leading silence removed, cut from 2 s to 750 ms (the rest was below
    -60 dBFS), 150 ms fade-out. The app waits for it at most 1.5 s on quit.
