# Screenshots

Screenshots for the project website, the wiki and the README. All of them show the UI running on
the built-in mock engine with fictional demo data (people, servers, messages, games and videos are
made up; addresses use `example.org`). Size: 1440×900 pixels (1×); only `main-dark.png` and `main-light.png` are 2880×1800 (2×), and `settings-privacy-messages-*.png` are 1440×1040 so the whole "Private messages" group fits. All files are 8-bit palette PNGs to keep the repository small. The default
look is the dark Mumcord theme; the main view, the theme editor and some settings also have a light
version.

The browser cannot play YouTube or receive a real screen share, so the watch-party and screen-share
shots show the real widgets with a placeholder picture (an abstract landscape) instead of a video
or a shared screen.

## Regenerating

1. Start two dev servers on free ports (not 1420) with the mock forced, ideally without hot
   reload so edits elsewhere do not reload a page mid-capture:
   `VITE_MUMCORD_MOCK=1 VITE_MUMCORD_MOCK_SEED=demo npx vite --port 1491` and
   `VITE_MUMCORD_MOCK=1 VITE_MUMCORD_MOCK_SEED=demoFresh npx vite --port 1492`.
2. Open them in a headless Chromium (Playwright) at 1440×900, device scale factor 2, locale
   `en-US`, in dark and light colour scheme, and drive the UI to each screen. Answer the
   "Check for new versions?" prompt with "No" first. The mock's controls (`getApi().mock`, e.g.
   `setTalking`, `focusServer`, `requireCertTrust`, `requirePassword`, `lockChannel`,
   `offerRejoin`, `receiveMessage`, `emit("userStatsChanged" | "screenSharesChanged" |
"watchPartyChanged" | "nowPlayingChanged", …)`) set up talking, connection figures, unread
   messages and mentions on other servers, password prompts, other people's shares and parties.
   Themes, friends, the private note and in-game overlay games are set through the normal UI
   and API.
3. Placeholders: the loopback player page (`http://localhost:43215/…`) is answered by the capture
   script with a static landscape page that reports "ready" to the app; for the screen-share
   viewer the script replaces `screenShareWatch` on the mock with one that sends a generated
   picture as RGBA frames (with `VideoDecoder` removed so the RGBA path is used).
4. Copy `main-dark.png` to `docs/images/mumcord-main.png` for the README.
