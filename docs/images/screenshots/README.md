## Regenerating

1. Start two dev servers on free ports (not 1420) with the mock forced:
   `VITE_MUMCORD_MOCK=1 VITE_MUMCORD_MOCK_SEED=demo npx vite --port 1437` and
   `VITE_MUMCORD_MOCK=1 VITE_MUMCORD_MOCK_SEED=demoFresh npx vite --port 1438`.
2. Open them in a headless Chromium (Playwright) at 1440×900, device scale factor 2, locale
   `en-US`, in dark and light colour scheme, and drive the UI to each screen. The mock's controls
   (`getApi().mock`, e.g. `setTalking`, `requireCertTrust`, `offerRejoin`, `receiveMessage`, `offerHistory`, `removeUser`, `emit("nowPlayingChanged", …)`) set up
   talking, the certificate prompt, the rejoin banner, unread messages, synced history and an
   offline friend; friends, the private note and the in-game overlay games are set through the
   normal UI and API.
3. The overlay window is `overlay.html` on the same server, captured at 640×400 (1280×800
   pixels) over a generated landscape that stands in for a game.
4. Copy `main-dark.png` to `docs/images/mumcord-main.png` for the README.
